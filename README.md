# TuSong — Canciones Personalizadas

Proyecto comercial dedicado a la creación y venta de **canciones personalizadas** como regalo emocional para ocasiones especiales (aniversarios, cumpleaños, bodas, homenajes, reconciliaciones y sorpresas), dirigido principalmente a **España** y **Estados Unidos**.

---

## 🎯 División de Roles (Regla de Oro del Proyecto)

* **Rol del Dueño (Dario) — Director Artístico y Productor Musical:**
  * Se encarga únicamente del trabajo creativo y de supervisión musical (componer/generar y curar las canciones con herramientas de IA musical, cuidar el sonido, la voz y la calidad artística final).
  * **Objetivo de tiempo:** Cero carga administrativa repetitiva ni trabajo de "asistente" llenando formularios manualmente.
* **Rol de la IA / Asistente — Estrategia, Copywriting, Creativos y Automatización:**
  * Redacta todas las publicaciones orgánicas, guiones de Reels/Shorts, copies publicitarios (en español e inglés), letras base de canciones, prompts de estilos, páginas/formularios web y configuraciones/scripts de campañas.

---

## 📂 Estructura del Proyecto

* [`assets/`](./assets/) — Logotipos oficiales de **TuSong** y piezas visuales de portada/perfil.
* [`CONTEXTO_Y_DATOS_TECNICOS.md`](./CONTEXTO_Y_DATOS_TECNICOS.md) — IDs reales de Facebook, Meta Ads, App de Meta, campaña de prueba creada y aprendizajes técnicos de la API.
* [`publicaciones/`](./publicaciones/) — Textos, ideas y estructura para publicaciones orgánicas en Facebook / Instagram / Reels.
* [`publicidad/`](./publicidad/) — Estrategia de validación de bajo riesgo, costos estimados, segmentación y textos de anuncios para Meta Ads y Google Ads / YouTube.
* [`canciones/`](./canciones/) — Flujo de producción musical, preguntas para el cliente y estructura de letras.
* [`scripts/`](./scripts/) — Espacio para scripts de automatización (Google Ads Scripts, webhooks, formularios o llamadas a API).
* [`PROMPT_NUEVA_CONVERSACION.md`](./PROMPT_NUEVA_CONVERSACION.md) — Prompt listo para copiar y pegar al iniciar una nueva conversación y retomar exactamente desde aquí.
